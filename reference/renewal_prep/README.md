# Reference - Renewal preparation

Three agents: portfolio analyst, offer specialist, writer. Compare with `labs/renewal_prep`.

## Run it

```bash
cd reference/renewal_prep
crewai install      # first time only, about a minute
crewai run          # uses the default inputs in src/renewal_prep/main.py
```

Or pass your own input: `uv run run_crew "2026-11-03"`
